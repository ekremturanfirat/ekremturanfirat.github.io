TabMaker

Paste a YouTube link — get guitar tab.

▶ Open TabMaker

Starts TabMaker on this computer and opens it in a new tab. Your browser will ask to open Start TabMaker — tick “Always allow” and click Open.

Already running? Go to localhost:8000.

First time on this computer?

  1. Get the TabMaker folder (a zip file) from Ekrem and unzip it, for example into Documents.
  2. Double-click Start TabMaker inside it. The first time, it may install Python — click Yes if Windows asks.
  3. TabMaker opens in your browser. From now on, the button above works.

Stopping

  1. Close the black TabMaker window.
