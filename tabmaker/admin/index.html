TabMaker

Paste a YouTube link — get guitar tab.

▶ Open TabMaker

Starts TabMaker on this computer and opens it in a new tab. Your browser will ask to open Start TabMaker — tick “Always allow” and click Open.

Already running? Go to localhost:8000.

First time on this computer?

  1. Download TabMaker.zip above, then right-click it → Extract All (for example into Documents).
  2. Open the TabMaker folder and double-click Start TabMaker. If Windows says “Windows protected your PC”, click More info → Run anyway (only once). The first time, it may install Python — click Yes if Windows asks.
  3. TabMaker opens in your browser. From now on, the Open TabMaker button above works.

Stopping

  1. Close the black TabMaker window.
